隱私權政策 / Privacy Policy

最後更新：2026-10-26 · 回首頁

適用範圍

line-bot 是僅供作者本人使用的個人工具，唯一授權的 Google 帳號屬於作者本人。

存取的 Google 使用者資料

經作者授權後，line-bot 透過 Google Drive、Docs、Sheets API 讀取與編輯 Google Drive 中的文件。實際可存取的範圍，僅限作者共用給該帳號的資料夾；程式也會拒絕操作該資料夾以外的檔案。line-bot 不會刪除檔案、變更共用權限或對外分享檔案。

資料的使用方式

文件內容只用於完成作者本人透過 LINE 下達的指令（例如讀取、整理、修改文件）。為完成指令，相關內容會傳送給 AI 模型供應商 Anthropic 處理。資料不會用於廣告、不會出售，也不會提供給其他第三方。

資料的儲存

OAuth 憑證只存放在作者自有的私人伺服器上，並限制存取權限。伺服器只保留操作紀錄（時間、檔案 ID、動作摘要），不保存文件全文。

撤銷與刪除

可隨時在 Google 帳戶的第三方存取權設定撤銷 line-bot 的存取權；撤銷後憑證立即失效，作者會一併刪除伺服器上的憑證與操作紀錄。

Google API 使用者資料政策

line-bot 使用及傳輸從 Google API 取得的資訊時，遵守 Google API Services User Data Policy，包括其中的 Limited Use 規定。

English summary

line-bot is a personal tool used only by its author. With the author's authorization, it reads and edits Google Drive, Docs, and Sheets files, limited to a folder the author shares with it. Content is used solely to carry out the author's own instructions and is processed by the AI provider Anthropic for that purpose. It is never sold, used for advertising, or shared with other parties. Credentials are kept on the author's private server, and only operation logs are retained, not document contents. Access can be revoked at any time in Google Account third-party access settings. line-bot's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
